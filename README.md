## 🎯 Tentang

### 💡 Latar Belakang

Di Indonesia, pengawasan proyek konstruksi publik masih menghadapi berbagai tantangan:

- 📉 **Kurang transparan** — masyarakat sulit mengakses progress & anggaran real-time
- 🗺️ **Sulit diverifikasi** — data tidak terkait dengan lokasi geografis spesifik
- 📢 **Minim partisipasi** — tidak ada kanal resmi untuk laporan masyarakat
- 🚫 **Rentan penyimpangan** — tidak ada cross-check antara penyedia, proyek, dan riwayat blacklist

### 🎯 Solusi CTW

**CTW** menjawab tantangan tersebut dengan mengintegrasikan:

| 🧩 Komponen | 🎯 Fungsi |
|---|---|
| 🗺️ **Peta Geospasial Interaktif** | Visualisasi proyek pada peta dengan filter wilayah 4 level |
| 📊 **Dashboard Transparansi** | Progress fisik, keuangan, kurva S, dan milestone per proyek |
| 📣 **Kanal Feedback Partisipatif** | 3 pilar: Audit • Inspeksi • Laporan Masyarakat |
| ⛔ **Registry Anti-Korupsi** | Database penyedia jasa + blacklist + dasar hukum |
| 🛰️ **Data Observasi Lapangan** | Integrasi dengan 20 variabel lingkungan & sosial-ekonomi |
| 🔒 **Keamanan Modern** | CSRF, rate limiting, session auth, upload validation |
| 🌐 **Desentralisasi** | Setiap organisasi dapat host instance-nya sendiri |

### 🎁 Keunikan

- **Open by design** — semua kode, data, dan metodologi terbuka untuk publik
- **Deploy anywhere** — bisa jalan di laptop, VPS, atau Cloudflare Tunnel
- **Zero-cost hosting** — tidak butuh server mahal, cukup PC + internet
- **Multi-tenant ready** — arsitektur mendukung banyak instance paralel

### 🚀 5 Langkah Cepat

```bash
# ─── LANGKAH 1: Clone repository ───────────────────────
git clone https://github.com/duhemen/ctw.git
cd ctw

# ─── LANGKAH 2: Buat environment Conda ─────────────────
conda env create -f environment.yml
conda activate ctw_env

# ─── LANGKAH 3: Setup environment variables ────────────
cp .env.example .env
# Generate SESSION_SECRET:
# python -c "import secrets; print(secrets.token_urlsafe(64))"
# Edit .env dan paste hasilnya ke CTW_SESSION_SECRET

# ─── LANGKAH 4: Inisialisasi database ──────────────────
python scripts/init_db.py
python scripts/import_wilayah.py
python scripts/import_observations.py
python scripts/init_admin.py

# ─── LANGKAH 5: Jalankan server ────────────────────────
uvicorn server.main:app --reload --port 8000
```

### 🛠️ Troubleshooting

<details>
<summary><strong>❌ Error: ModuleNotFoundError</strong></summary>

Pastikan environment aktif:
```bash
conda activate ctw_env
python -c "import fastapi; print(fastapi.__version__)"
```
</details>

<details>
<summary><strong>❌ Error: TemplateNotFound</strong></summary>

Cek struktur folder:
```bash
ls server/templates/
# Harusnya ada: base.html, dashboard.html, feedback.html, admin/
```
</details>

<details>
<summary><strong>❌ Error: Port 8000 already in use</strong></summary>

Ganti port:
```bash
uvicorn server.main:app --reload --port 8001
```
</details>

<details>
<summary><strong>❌ Peta tidak muncul</strong></summary>

Pastikan koneksi internet aktif (Leaflet CDN + OpenStreetMap tiles butuh online).
</details>

## 📡 API Endpoints

### 🌐 Public API

<details>
<summary><strong>🗺️ Regions — Hierarki Wilayah</strong></summary>

| Method | Endpoint | Deskripsi |
|---|---|---|
| `GET` | `/api/regions` | List wilayah (filter by level & parent) |
| `GET` | `/api/regions/search?q=cibinong` | Search wilayah by nama |
| `GET` | `/api/regions/{code}/path` | Hierarki lengkap wilayah |
| `GET` | `/api/regions/{code}/geojson` | GeoJSON batas wilayah |
| `GET` | `/api/regions/geojson/collection` | Collection GeoJSON children |

</details>

<details>
<summary><strong>🏗️ Projects — Data Proyek & Dashboard</strong></summary>

| Method | Endpoint | Deskripsi |
|---|---|---|
| `GET` | `/api/dashboard` | Statistik dashboard ter-filter |
| `GET` | `/api/projects/{id}/detail` | Detail lengkap 1 proyek |
| `GET` | `/api/projects` | List proyek (legacy) |
| `GET` | `/api/projects/{id}/nearby_observations` | Observasi radius X km |

</details>

<details>
<summary><strong>🏢 Providers — Penyedia & Blacklist</strong></summary>

| Method | Endpoint | Deskripsi |
|---|---|---|
| `GET` | `/api/providers` | List penyedia jasa |
| `GET` | `/api/blacklist` | List penyedia blacklist aktif |

</details>

<details>
<summary><strong>🛰️ Observations — Observasi Lapangan</strong></summary>

| Method | Endpoint | Deskripsi |
|---|---|---|
| `GET` | `/api/observations` | List observasi (filter wilayah/severity) |
| `GET` | `/api/observations/variables` | Katalog 20 variabel observasi |
| `GET` | `/api/observations/stats` | Statistik agregat |

</details>

### 🔐 Admin API

<details>
<summary><strong>🔑 Authentication</strong></summary>

| Method | Endpoint | Deskripsi |
|---|---|---|
| `GET` | `/admin/login` | Halaman login |
| `POST` | `/admin/login` | Submit login (rate limited 5/menit) |
| `GET` | `/admin/logout` | Logout & clear session |

</details>

<details>
<summary><strong>🛠️ CRUD Operations</strong></summary>

| Method | Endpoint | Deskripsi |
|---|---|---|
| `GET/POST` | `/admin/projects/*` | CRUD proyek |
| `GET/POST` | `/admin/providers/*` | CRUD penyedia |
| `GET/POST` | `/admin/blacklist/*` | CRUD blacklist |
| `POST` | `/admin/feedback/{id}/status` | Update status feedback |
| `POST` | `/admin/projects/{id}/photos/upload` | Upload foto proyek |
| `POST` | `/admin/projects/{id}/photos/{pid}/delete` | Hapus foto |

</details>

### 📖 Interactive Docs

## 🔒 Keamanan

CTW mengimplementasikan **best practices** keamanan web modern:

<table>
<tr>
<td width="50%" valign="top">

### ✅ Yang Sudah Diimplementasikan

- 🔐 **Password hashing** — PBKDF2-SHA256 dengan 100.000 iterasi
- 🛡️ **CSRF protection** — Token per session, validated di semua POST
- 🚦 **Rate limiting** — Login: 5/menit, Form: 10/menit, API: 60/menit
- 🍪 **Session security** — SameSite=Lax, HTTPS-only di production
- 📁 **Upload validation** — Extension whitelist + size limit + filename sanitization
- 🔒 **SQL injection** — Dicegah via SQLAlchemy ORM (parameterized queries)
- 🚫 **Path traversal** — Dicegah di file handling
- 📖 **Docs protection** — `/docs` dinonaktifkan di production
- 🔑 **Session secret** — Persistent via `.env`, bukan random per restart

</td>
<td width="50%" valign="top">

### 🚧 Yang Sedang Dikembangkan

- 🔐 **JWT + RBAC** — Multi-role (admin, auditor, inspector, viewer)
- 🌐 **CORS policy** — Untuk akses dari domain eksternal
- 🔏 **Audit log** — Track semua perubahan data penting
- 🛰️ **2FA** — Optional two-factor authentication
- 🕵️ **Anomaly detection** — Deteksi pola akses mencurigakan
- 📜 **HTTPS enforcement** — Redirect HTTP → HTTPS otomatis
- 🧪 **Automated security scan** — Bandit + Snyk di CI/CD

</td>
</tr>
</table>
